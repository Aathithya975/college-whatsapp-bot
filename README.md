A WhatsApp bot for college students — get timetables, announcements, attendance info, and more via chat.

College WhatsApp Bot is an automated WhatsApp bot built to help college students and faculty 
get instant information through WhatsApp messages — no app needed.

Features:
- 📅 Timetable queries by class/department
- 📢 Announcements & notice board updates
- 📋 Attendance status alerts
- 🤖 Auto-reply to common student queries
- 📌 Exam schedule & holiday info

Built with Python / Node.js and WhatsApp Web / Twilio / Baileys API.

Developed a College WhatsApp Bot as a mini project that automates student communication 
through WhatsApp. Students can query timetables, get announcements, and receive attendance 
updates — all via WhatsApp chat without any additional app.

Tech Stack: Python / Node.js, WhatsApp API / Twilio / Baileys, Flask / Express
